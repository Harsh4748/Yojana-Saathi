# 08 - Presentation & Demo Guide

## Slide Structure (7-8 slides)
1. **Title:** Yojana Saathi + tagline
2. **Problem:** Scheme hai, par logo tak nahi pahunchti (official source se statistic daalo)
3. **Real Story:** Kisi student/kisan se baat karke ek real example
4. **Solution:** 4 steps: Profile -> Match -> Samjho -> Apply
5. **How it works:** Architecture diagram (React, Node, MongoDB, AI) + "Code decides, AI explains"
6. **Live Demo**
7. **Impact & Future Scope:** Zyada states, OCR, WhatsApp bot, mobile app
8. **Team + Thank you**

## Demo Script (3 minute)
1. "Ye Ramesh hai, Gujarat ka OBC student, family income 2 lakh."
2. Language Gujarati/Hindi select karo.
3. **Voice se** 2-3 sawal ka jawab do (wow moment).
4. Results: "5 schemes mili, 1 near-miss."
5. Ek scheme kholo, documents checklist dikhao.
6. Chatbot se puchho: "Income certificate kahan banta hai?"
7. WhatsApp share dabao.
8. Close: "2 minute mein wo kaam jo pehle 3 din leta tha."

## Judges ke Possible Sawal
| Sawal | Jawab |
|---|---|
| Ye ChatGPT wrapper to nahi? | Nahi. Eligibility rule engine se hoti hai, AI sirf explain karta hai. Data curated hai. |
| Data kaise update hoga? | Admin panel + `lastVerifiedOn`; future mein official portals se sync. |
| AI galat bataye to? | AI sirf given context se jawab deta hai, final eligibility code se, aur disclaimer hai. |
| Privacy? | User ka profile DB mein save nahi hota. |
| Revenue / sustainability? | NGO/government partnership, CSR funding, free public utility. |
| Scale kaise hoga? | Naye states sirf data add karke, code change nahi. |
| Kaise pata chale users ko help mili? | Feedback + anonymous analytics. |

## Tips
- Demo live karo, slides kam rakho.
- Pehle se test profile ready rakho.
- Backup video zaroor rakho.
- Numbers/statistics sirf verified source se bolo.
- Team ke har member ko kuch bolne ka mauka do.
